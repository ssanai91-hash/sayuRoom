## 변환 방법

1. 공개 ZIP의 `디지털콘텐츠_OBJ` 안에 있는 OBJ 및 8192px 색상·노멀 JPG를 사용했다. 좌우 각각 원본 267,636 / 266,890삼각형이다.
2. Z축 위·밀리미터 좌표를 Y축 위·미터로 바꾸고, 현재 박물관 안내 높이(0.815 / 0.908m)에 맞췄다. UV가 붙은 원본 표면을 유지하면서 PyMeshLab의 텍스처 인식 quadric edge-collapse로 120,000삼각형까지 줄였다. 경계·면 방향 보존을 켰다.
3. 원래 색상 및 노멀 맵을 2048×2048 이하로 축소했다. 노멀 벡터를 재정규화하고 JPEG로 내장했다. 외부 사진이나 새 텍스처를 합성하지 않았다.
4. UV 경계의 정점을 분리해 질감을 유지하고, glTF 2.0 바이너리로 저장했다. Draco 등 별도 디코더는 쓰지 않는다. 추가 실행 라이브러리도 없다.
5. 원래 유물의 의자·옷자락·연꽃 받침까지 포함하고, 피벗은 받침 바닥의 경계상자 중앙으로 잡았다. 박물관의 검은 전시용 원기둥은 포함하지 않았다. 얼굴은 +Z를 향한다.

초기 재질은 원본 색상·노멀 맵과 일괄 metallic .45 / roughness .5였다. 현재는 아래 1단계 파생 ORM을 사용한다. 원본 색상·노멀·12만 삼각형 형상은 그대로 보존한다. 재질은 실측 물성치가 아닌 원본 스캔 색의 보수적인 추정이다.

## 검증

두 GLB를 다시 읽어 파일당 8,000,000바이트 이하, 150,000삼각형 이하, 2048px 이하 JPEG 텍스처 내장, Draco 미사용, Y축 위·바닥 높이 0·미터 크기를 확인했다. 실제 변환 GLB를 앞·옆·뒤에서 렌더링해 형상·UV를 확인했다. 사유의 방 실기기 배치 화면은 클로드의 연결 후 검증한다.

## 1단계 실사 질감 — 원본 스캔에서 파생한 ORM / AO

- 제공·저작권: 국립중앙박물관, 공공누리 제1유형(출처표시). 위 원본 ZIP 안 OBJ와 원본 스캔 색상만 사용했다. 블로그 사진·생성 이미지·추가 학습·사진 색 추출은 사용하지 않았다.
- **원본 스캔 형상에서 파생한 AO**: 왼쪽 267,636 / 오른쪽 266,890 삼각형 OBJ를 기존 변환과 같은 좌표·실물 규격에 맞추고 현재 120,000삼각형 모델의 UV 텍셀을 원본 형상으로 투영했다. 1024², 텍셀당 코사인 반구 128방향, 최대 0.18m, 표면 오프셋 0.45mm·양방향 12mm 투영 케이지. UV 여백을 확장하고 약한 필터링으로 섬 경계·샘플 잡음을 줄였다.
- 금속성·거칠기: 원본 내장 스캔 색상에서 연속 가중치로 금박·녹/회색 부식·어두운 청동을 분리했다. 밝기 하나로 판별하지 않고 노랑/황토 색차와 채도를 함께 사용하며 흰 촬영 반사 얼룩은 금박에서 제외한다. 중립 회색도 밝은 흰 반사 영역은 제외한다. 색상 기반 추정이므로 재료의 실측 분류로 보장하지 않는다.
- **B 방식**: ORM PNG 1024²를 사전 생성해 각 GLB에 내장했다. R=AO, G=roughness, B=metalness. PNG는 선형 데이터로 읽고, 채널당 64단계로 압축 효율을 높였다(원래 8bit 값 대비 최대 오차 2/255). 경계는 연속 가중치와 텍스처 필터링으로 섞는다. 휴대폰의 캔버스 분석·생성 단계는 없다.
- 각 GLB에 PNG 하나만 추가하고 AO와 metallicRoughness가 같은 텍스처를 공유한다. glTF factor는 1, AO strength는 0.8. 기존 모든 바이너리 바이트가 동일함을 확인했다. `normalScale=.65` 유지. 신규 4K 텍스처·고해상도 모델 교체·압축 디코더·외부 실행 라이브러리는 없다.
